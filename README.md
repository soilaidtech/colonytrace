# ColonyTrace

ColonyTrace is SoilAid Technologies' production traceability and operations management system for Black Soldier Fly Larvae (BSFL) production.

## Project Overview

ColonyTrace is a production traceability and operations management system designed for Black Soldier Fly Larvae (BSFL) farms. The project aims to enable reliable data tracking throughout BSFL production to support traceability, record keeping, production monitoring, and farm operations management.

ColonyTrace is intended for BSFL farm managers, production managers, operators, and directors who need to record production activities, monitor farm performance, trace production inputs and outputs, and access reports or dashboards showing the operational health of the farm.

The system is designed primarily for rural production environments where internet connectivity may be intermittent or unreliable. Field operations therefore need to continue even when an internet connection is unavailable.
